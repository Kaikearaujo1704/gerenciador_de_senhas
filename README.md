# 🔐 Gerenciador de Senhas

Um gerenciador de senhas desenvolvido em **Python**, criado para praticar programação, organização de dados e integração com banco de dados.

## 📌 Sobre o projeto

O projeto tem como objetivo criar uma aplicação simples para gerenciamento de senhas, utilizando Python para a lógica da aplicação e uma estrutura separada para trabalhar com o banco de dados.

A aplicação foi desenvolvida como projeto de estudo, buscando colocar em prática conceitos de **programação em Python**, organização de código e armazenamento de informações.

## 🛠️ Tecnologias utilizadas

* 🐍 **Python**
* 🗄️ **Banco de dados**
* 💻 **Aplicação via terminal**

## 📂 Estrutura do projeto

```text
gerenciador_de_senhas/
│
├── Main.py
├── database.py
└── README.md
```

### `Main.py`

Arquivo principal da aplicação, responsável pela execução e interação com o sistema.

### `database.py`

Arquivo responsável pela parte relacionada ao banco de dados e pelo gerenciamento das informações armazenadas pela aplicação.

## 🎯 Objetivos

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Kaikearaujo1704/gerenciador_de_senhas.git
```

### 2. Entre na pasta

```bash
cd gerenciador_de_senhas
```

### 3. Execute o programa

```bash
python Main.py
```

> Dependendo da configuração do computador, pode ser necessário utilizar `python3 Main.py`.
